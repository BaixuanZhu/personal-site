## Overview

Prism is a React component library for admin and dashboard scenarios. It connects the whole chain — from the design spec (Design Tokens) down to component implementation — so products across business lines stay visually and behaviorally consistent.

## Architecture

### Design Tokens driven

Every visual attribute (color, radius, spacing, type scale) converges into a single token source file, compiled into both CSS Variables and a Tailwind theme. Designers change it once; every product line updates:

```json
{
  "color": {
    "primary": { "value": "oklch(0.55 0.2 260)" },
    "radius": { "value": "0.625rem" }
  }
}
```

### Headless components + separate styling layer

Interaction logic builds on Radix UI's headless primitives while the styling layer uses Tailwind — teams can use it out of the box, or take just the logic and write their own styles.

## Quality Assurance

- All **60+ components** cover keyboard navigation and ARIA attributes, passing axe accessibility scans
- Every component ships with visual regression tests, so style drift is caught in CI
- Storybook docs double as tests — example code can be pasted straight into business codebases

## Reflections

The hardest part of a component library is restraint — every "handy little feature" becomes long-term maintenance cost. We introduced an RFC process: a new component must first prove that at least two product lines need it.
